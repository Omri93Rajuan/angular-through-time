# Research v2 manifests

This directory is a new research namespace. Historical `baseline` and `idiomatic` identifiers retain their original meaning and bytes. The historical catalog records SHA-256 digests without editing old files. `idiomatic-v2` is a new architecture, never a relabeling of old timings.

Version manifests declare state, publication/equality, component graph, scheduler, stable control flow, exact versions and builder policy. `portable-default` source is an imperative adapter for native CLI workspaces; its generated webpack target is a source-development convenience, not native-default evidence. The actual CLI configuration is captured under `research/native/` and `native/`. `m4-zone` is the same Angular 22 signal graph with explicit Zone scheduling. Only primary and matched variants may enter timing pilots; diagnostic variants cannot.

`protocol.json` authorizes only exploratory pilots. Main-campaign duration, independent run count, precision, selected comparisons and multiplicity decisions require researcher approval. No approval is implied by running tests or pilots.
