# Verified launch facts

Use the [research report](RESEARCH_V2_REPORT.md) and raw linked evidence for the exact revision and coverage. These are safe engineering statements, not performance rankings.

- Angular Through Time is an open-source research apparatus by **Omri Rajuan**, covering exact pinned Angular 14–22 releases with reproducible source and lockfiles.
- It preserves the original controlled and limited idiomatic implementations and all 325 cataloged historical result files. Historical revision-signal observations are not relabeled as a full Signals architecture.
- New implementations use seven component roles and explicit OnPush. Older versions use optimized immutable publication; Angular 17+ uses actual signal state and computed derivations. Stable control flow starts at 18 and stable zoneless scheduling at pinned 20.3.
- Native CLI recipes were actually generated and preserved. Their selected builders are webpack `browser` on 14–16, devkit `application` on 17–19, and `@angular/build:application` on 20–22. Default budgets and configurations are preserved.
- Expanded browser correctness checks cover numeric rows and panels, chart calculations, selected live prices, three update modes, filters, sorting, watch state, asynchronous delivery, zero work and focus/identity. Exact accepted artifacts and failures are recorded separately from timings.
- An instrumented Angular 22 diagnostic demonstrates one row-template evaluation for a one-row mutation and a single watch toggle. It distinguishes lifecycle-hook traversal from template refreshes. This narrow result does not establish that all workloads or versions have the same behavior.
- The historical replay audit retains 330 late updates and seven outlier flags; correctness acceptance is not a claim that the target update rate was sustained.
- New runtime measurements are exploratory pilots only. The main confirmatory campaign has not run and requires researcher approval of protocol and sample size.
- The repository includes English methods, replication instructions, provenance, failed attempts, a separate v2 dashboard and `CITATION.cff`. No DOI, affiliation, peer-review status or universal superiority claim is implied.

Do **not** announce that Angular 22 is universally faster, that Signals alone caused a cross-version improvement, that esbuild/Vite explains a runtime result, that the application sustains arbitrary incoming traffic, or that pilot confidence intervals establish statistical significance. Do not describe compilation-only CI as a performance campaign. Publication or release remains subject to owner approval.
